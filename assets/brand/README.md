# MORI 브랜드 원본

사용자가 제공한 SVG 5개를 변경 없이 보관합니다. SVG 안의 글자는 이미 경로로 변환되어 있어 별도 폰트가 필요하지 않습니다.

| 파일 | 용도 |
| --- | --- |
| MORI_symbol.svg | 단독 심볼 |
| MORI_logo1.svg | 밝은 배경의 컬러 로고와 어두운 글자 |
| MORI_logo2.svg | 어두운 배경의 컬러 로고와 흰 글자 |
| MORI_logo3.svg | 단색 로고 |
| MORI_logo_app.svg | 앱 실행 아이콘 |

앱 상단에는 주간 logo1, 야간 logo2를 사용합니다. 단독 심볼과 단색 버전도 Android 리소스로 준비되어 있습니다. 앱 아이콘은 제공된 배경과 심볼을 Adaptive Icon 레이어로 나누고 OS의 마스크와 안전 영역에 맞게 여백을 확보합니다. Android 13 이상의 단색 테마 아이콘도 지원합니다.

Android에서는 SVG를 런타임 라이브러리로 읽지 않고, 원본의 경로/색상/그라데이션을 VectorDrawable로 변환합니다. 원본은 수정하지 않습니다. 단독 심볼 리소스는 표시 여백만 정리하고, 아이콘 전경에는 마스크 안전 여백을 추가합니다.

저장소 루트에서 `python3 tools/convert_brand_assets.py`를 실행하면 Android 리소스를 다시 생성합니다. 추가 Python 패키지는 필요하지 않습니다. 현재 변환기는 이 원본에 사용된 path, rect, 선형 그라데이션과 even-odd 채움만 처리하며, 지원하지 않는 형태가 생기면 오류를 표시합니다.

원본 그라데이션 색: #7499FF → #4248E0, #C8ABFB → #94A5FB. 글자색: #242433 또는 흰색. 앱의 조작 버튼/본문 색상은 가독성을 위한 기존 UI 토큰을 유지합니다.
