# MORI 디자인 시스템 v0.1

## 시각적 방향

제공된 로고 초안의 둥근 리본형 M, 블루에서 라벤더로 이어지는 그라데이션, 짙은 네이비, 밝은 보라색 배경을 해석했습니다. 아래 색은 초안에서 도출한 개발용 근사값입니다. 최종 로고 원본의 공식 색상이나 폰트 명세는 아닙니다. 앱 심볼은 초안의 형태를 Android 벡터와 Compose Canvas로 재구성했습니다.

그라데이션은 브랜드 표식, 선택 강조, 음악 아트워크에 집중합니다. 본문과 측정값은 단색으로 표시합니다. 표면은 흰색과 옅은 보라색으로 구분하고 그림자, 발광, 투명 효과를 절제합니다.

## 코드 기준

`android/app/src/main/java/com/cheonsaeun/mori/design/MoriTheme.kt`가 색상, 글꼴 크기, 간격, 모양, 모션의 기준입니다. 공통 패널, 상태 배지, 아이콘, 지표 카드는 같은 폴더의 `MoriComponents.kt`에 있습니다. 앱 상단의 스타일 가이드에서 팔레트와 컴포넌트를 확인할 수 있습니다.

| 용도 | 값 | 적용 |
| --- | --- | --- |
| Primary | #555DEB | 주요 선택, 버튼, 강조 값 |
| Blue | #748FFF | 심볼, 그라데이션 |
| Lavender | #C5A9F4 | 그라데이션, 장식 |
| Navy | #171A36 | 음악 패널, 앱 아이콘 |
| Ink | #202132 | 제목과 본문 |
| Secondary | #62677F | 보조 설명 |
| Canvas | #F5F5FC | 앱 배경 |
| Outline | #E0E2EF | 카드 경계 |
| Heat | #B94745 / #FFEFEB | 열선 글자 / 배경 |
| Cool | #216F97 / #E8F5FC | 통풍 글자 / 배경 |
| Success | #22785B / #E9F5EF | 실제 차량 응답 확인 |

보라색은 선택을 뜻합니다. 열선과 통풍에는 별도의 의미색을 사용합니다. 색만으로 상태를 전달하지 않고 아이콘과 문구를 함께 표시합니다. 라벤더는 밝은 배경 위 작은 글자색으로 사용하지 않습니다.

## 글자와 레이아웃

- 제목 32/42, 큰 강조 36/48, 카드 제목 24/34, 본문 18/28, 보조 설명 14/21. 단위는 sp이며 글자 크기/줄 높이입니다.
- 기본 시스템 SansSerif를 사용합니다. 외부 폰트 라이선스나 네트워크 다운로드에 의존하지 않습니다.
- 간격 4 / 8 / 12 / 16 / 24 / 32 dp.
- 모서리: 작은 지표 16, 좌석 카드 22, 큰 패널 28 dp.
- 주요 터치 영역 기준 64 dp 이상. 좌석 카드는 전체를 선택할 수 있습니다.
- 좌석 선택 전환 220ms. 지속적인 장식 애니메이션은 사용하지 않습니다.
- Pleos 가로형 앱 영역을 기준으로 좌석 공간 56%, 공통 공간 44%로 구성합니다. 음악 상태와 공조 구역은 별도 패널입니다.

## 정보 구조

### 각자의 자리

4개 좌석의 물리적 배치를 유지합니다. 각 좌석에는 탑승 여부, 등받이 위치값, 열선, 통풍이 표시됩니다. 좌석을 선택하면 아래쪽에서 선택한 좌석의 자세 정보를 다시 확인할 수 있습니다. 시트 그림은 상태 개념도이며 실제 차량의 형상이나 물리적 각도를 재현하지 않습니다.

현재 SDK의 등받이 반환값은 위치값입니다. 도 단위로 변환하거나 각도라고 단정하지 않습니다. 좌석 점유 정보로 사람의 신원을 추정하지 않습니다. 실제 차량 모드에서는 운전자/동승자로 표시하고, 이름은 명시적 프로필 연결 기능이 생긴 뒤 연결합니다.

### 함께하는 공간

공조와 음악/라디오는 모든 탑승자가 공유하는 경험으로 오른쪽에 모읍니다. 공조의 실제 제어 구역은 그대로 표시합니다. 독립 온도 구역을 하나의 공통 온도로 합치거나 뒷좌석 지원을 가정하지 않습니다. 같은 영역이 온도/풍량/전원에 모두 제공되지 않으면 지원되는 지표만 표시합니다. 공조 설정 온도는 실제 실내 온도와 구분합니다.

음악/라디오 탭은 공통 패널의 콘텐츠 유형을 전환합니다. 현재 실제 재생, 외부 음악 앱 상태, 라디오 수신 기능은 연결되지 않았으며 해당 상태를 화면에 명시합니다.

## 실제 상태와 미리보기

- 기본 화면은 실제 차량 모드입니다. 화면이 활성화된 동안 조회 완료 후 약 2초 간격으로 다시 조회합니다.
- 기능마다 capability와 조회 가능 영역을 먼저 확인합니다. 지원되지 않는 좌석과 값은 미지원으로 표시합니다.
- 초기 확인 중, 미지원, 확인 불가, 실제 값 0을 별도로 처리합니다. 응답 실패를 꺼짐으로 표시하지 않습니다.
- 디자인 미리보기는 사용자가 직접 켜는 명시적 예시입니다. 헤더와 하단에 예시 표시가 나오며 이름, 탑승자, 설정을 차량에 전송하지 않습니다.
- 예시 데이터는 `ui/preview/PreviewSnapshot.kt`에 격리합니다. 차량 조회 실패 시 이 데이터로 자동 대체하지 않습니다.
- 현재 모든 SDK 동작은 읽기 전용입니다. 좌석 선택과 음악/라디오 탭 선택은 화면 표시만 바꿉니다.
