# MORI 디자인 시스템 v0.2

## 시각적 방향

제공된 로고 초안의 둥근 리본형 M, 블루에서 라벤더로 이어지는 그라데이션, 짙은 네이비, 밝은 보라색 배경을 해석했습니다. 아래 색은 초안에서 도출한 개발용 근사값입니다. 최종 로고 원본의 공식 색상이나 폰트 명세는 아닙니다. 앱 심볼은 초안의 형태를 Android 벡터와 Compose Canvas로 재구성했습니다.

그라데이션은 브랜드 표식, 선택 강조, 음악 아트워크에 집중합니다. 본문과 측정값은 단색으로 표시합니다. 표면은 흰색과 옅은 보라색으로 구분하고 그림자, 발광, 투명 효과를 절제합니다.

## 코드 기준

`android/app/src/main/java/com/cheonsaeun/mori/design/MoriTheme.kt`가 색상, 글꼴 크기, 간격, 모양, 모션의 기준입니다. 공통 패널, 상태 배지, 아이콘, 지표 카드는 같은 폴더의 `MoriComponents.kt`에 있습니다. 스타일 가이드 진입 버튼은 실제 앱 화면에서 제거했습니다. 디자인 기준은 이 문서와 코드 토큰에서 관리합니다.

| 용도 | 값 | 적용 |
| --- | --- | --- |
| Primary | #5058D8 | 주요 선택, 버튼, 강조 값 |
| Blue | #748FFF | 심볼, 그라데이션 |
| Lavender | #C5A9F4 | 그라데이션, 장식 |
| Navy | #171A36 | 음악 패널, 앱 아이콘 |
| Ink | #202132 | 제목과 본문 |
| Secondary | #62677F | 보조 설명 |
| Canvas | #F5F5FC | 앱 배경 |
| Outline | #E0E2EF | 카드 경계 |
| Heat | #B94745 / #FFEFEB | 열선 글자 / 배경 |
| Cool | #216F97 / #E8F5FC | 통풍 글자 / 배경 |
| Success | #22785B / #E9F5EF | 실제 차량 응답 확인 |

보라색은 선택을 뜻합니다. 열선과 통풍에는 별도의 의미색을 사용합니다. 색만으로 상태를 전달하지 않고 아이콘과 문구를 함께 표시합니다. 라벤더는 밝은 배경 위 작은 글자색으로 사용하지 않습니다.

## 글자와 레이아웃

- 제목 32/42, 큰 강조 36/48, 카드 제목 24/34, 본문 22/32, 보조 설명 18/27. 단위는 sp이며 글자 크기/줄 높이입니다.
- 기본 시스템 SansSerif를 사용합니다. 외부 폰트 라이선스나 네트워크 다운로드에 의존하지 않습니다.
- 간격 4 / 8 / 12 / 16 / 24 / 32 dp.
- 모서리: 작은 지표 16, 좌석 카드 22, 큰 패널 28 dp.
- 주요 버튼 80dp 이상, 큰 탭 88dp 이상. 좌석 카드는 전체를 선택할 수 있습니다.
- 좌석 선택 전환 220ms. 지속적인 장식 애니메이션은 사용하지 않습니다.
- 통합 화면은 좌석 공간 60%, 공통 카드 40%입니다. 프로필 관리는 별도 설정창입니다. 폭 1050dp 미만이면 세로 배치하며 각 영역을 스크롤합니다.

## 정보 구조

기본 화면에서 좌석 4개의 현재 설정과 공조/미디어의 선호 일치 여부를 함께 보여줍니다. 좌석에서 탑승자 변경과 저장/복원을 시작합니다. 프로필 관리와 모든 선호 선택은 큰 팝업을 사용하며 탑승 우선 정렬과 관계 필터를 공유합니다.

자세/열선/통풍은 차량 현재 값이며, 공조는 저장 선호와 현재 상태의 일치 여부를 요약합니다. 인식된 사람의 이름을 자동 추정하지 않습니다. 예시 시나리오는 실제 데이터와 별도의 메모리 세션으로 관리합니다.

## 색상과 피드백

밝은 테마의 주요 글자색/표면 조합을 계산했습니다. Primary/Soft, Secondary/Soft, Heat/HeatSoft, Cool/CoolSoft는 4.5:1 이상입니다. 장식용 그라데이션에 본문을 얹지 않습니다. OS 야간 모드에서는 Canvas #141625, Surface #1D2033, Soft #282B43, Primary #ADB5FF, Ink #ECECF7로 전환합니다. 음악 패널은 네이비를 유지합니다.

처리 중 표시를 먼저 노출하고 실제 응답 확인을 기다립니다. 주요 버튼은 플랫폼의 가상 키 터치 피드백을 요청합니다. 하드웨어와 OS 설정에 따라 진동은 없을 수 있습니다. 지속적인 장식 애니메이션과 자동 텍스트 스크롤은 사용하지 않습니다.

## 실제 상태와 미리보기

조회가 완료된 뒤 약 1초 간격으로 상태를 다시 확인합니다. 지원 여부와 실제 값 0, 확인 중, 확인 불가를 구분합니다. 에뮬레이터의 좌석 3축과 점유 상태는 debug 전용 실시간 콘솔 어댑터로 보완합니다. 실제 차량용 빌드는 Vehicle SDK 조회를 사용합니다.

예시 시나리오는 가족 프로필을 포함하며 예시 안에서 저장과 설정 적용을 체험할 수 있습니다. 실제 저장소/차량에는 전달하지 않습니다. 조회 실패를 예시 데이터로 자동 대체하지 않습니다. 프로필 적용/갱신과 현재 이동의 연결은 [사용 안내](PROFILE_DASHBOARD.md)를 참고합니다.

주행 제한과 실제 차량 제어 권한, 음원 재생은 후속 검증 범위입니다. 실제 패널의 물리적 글자 크기와 모든 표시 모드에 대한 Pleos 인증을 완료한 상태는 아닙니다.
