# 프로필 대시보드

## 개별 좌석

1. 좌석 카드를 눌러 적용할 좌석을 선택합니다.
2. **현재 설정 저장**을 누르면 오른쪽에 현재 자세와 열선/통풍을 가져온 편집 화면이 열립니다. 이름을 입력하고 저장하면 해당 좌석에 프로필이 연결됩니다.
3. 기존 프로필은 **프로필 보기 → 선택 좌석에 불러오기**로 연결합니다. 상세 화면에 표시된 자세와 열선/통풍을 지원 범위에서 적용합니다.
4. 직접 설정을 바꾸면 **저장 후 설정 변경됨**으로 표시됩니다. **현재 설정으로 수정**을 눌러 변경한 자세를 검토한 뒤 저장합니다.
5. 프로필의 공조/미디어 선호는 편집 화면의 각 탭에서 수정합니다. 삭제와 좌석 연결 해제는 프로필 상세에 있습니다.

앱을 다시 실행해도 프로필은 유지합니다. 사람과 좌석의 연결은 앱 실행 중의 명시적 선택으로 관리하며, 재실행 때 자동으로 사람을 배정하지 않습니다. 차량에서 확인할 수 없는 값은 신규 생성 시 비워두고, 기존 프로필 갱신 시 이전 값을 유지합니다. ‘유지’는 해당 항목을 변경하지 않는다는 뜻입니다.

## 공통 기능

왼쪽 위에는 현재 공조 구역별 온도와 공유 풍량을 표시합니다. 아래 프로필 목록의 **공조에 적용**은 그 사람의 등록 온도를 확인 가능한 앞좌석 온도 구역들에 적용하고, 등록 풍량을 지원 공유 구역에 적용합니다. 구역별 현재 값은 계속 따로 표시합니다. 이 단계는 한 사람의 선호를 선택하는 방식이며 다자간 자동 조율은 후속 구현입니다.

오른쪽은 현재 선택된 음악 장르 또는 라디오 채널 선호와 프로필별 선호 목록입니다. **미디어 선호 적용**은 MORI 세션의 선호만 바꿉니다. 실제 음원 재생, 차량의 다른 음악 앱 조회, 외부 플랫폼 연동은 포함하지 않습니다.

## 적용과 저장

적용 중에는 진행 상태를 즉시 표시하고 중복 적용을 제한합니다. 설정 전송 후 상태를 다시 조회하며, 반영 확인/확인 필요/실패/미지원 안내를 구분합니다. 여러 요청은 차례로 실행되며 일부만 적용될 수 있습니다. 수동 변경을 자동으로 다시 덮어쓰지 않습니다.

debug 앱은 공식 Pleos 2.1 콘솔을 통해 제어합니다. 좌석 3축과 탑승 상태는 이 이미지의 실시간 콘솔 값으로 보완하며, 공조와 열선/통풍은 SDK 응답으로 표시합니다. 현재 검증한 제어 범위는 4개 좌석 자세, 앞좌석 열선/통풍, 앞좌석 온도와 공유 풍량입니다. 뒷좌석 열선 프로필 자동 적용과 실제 차량용 제어는 검증 전이므로 적용 대상에서 제외합니다.

프로필은 기기 내부에만 저장합니다. 이름/별명과 동의한 선호를 등록하며 원음, 연락처, 설문 응답은 저장하지 않습니다. 디자인 미리보기에서는 저장과 설정 적용을 비활성화합니다.

## 화면 기준

[공식 Pleos 디자인 가이드](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro)를 참고했습니다. 큰 탭 88dp, 주요 버튼 80dp 이상을 적용하고, 처리 중 표시와 기본 터치 피드백을 제공합니다. 가로 앱 영역이 1000dp 미만이면 세로로 배치하고 스크롤을 사용합니다. 주요 두 탭과 프로필 편집은 같은 조작 패턴을 사용합니다. OS 테마에 따른 주야간 팔레트를 제공합니다.

공식 인증 완료를 뜻하지 않습니다. 실제 패널의 물리적 글자 크기, 모든 해상도, 주행 중 제한, 외부 음성/오디오 정책은 별도 확인이 필요합니다. 이번 검증은 1700x1184 앱 영역과 1256x800, 648x800 제약에서 수행했습니다.
