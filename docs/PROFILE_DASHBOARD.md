# 통합 차량 대시보드

최종 개편: 2026-11-12

## 현재 상태와 조절

기본 화면은 왼쪽의 4개 좌석과 오른쪽의 공조/미디어 카드로 구성합니다. 좌석의 이름/자세 영역 또는 열선/통풍 영역을 누르면 조절창이 열립니다. 이 창의 적용은 현재 차량 상태만 바꾸며 저장 프로필을 자동으로 덮어쓰지 않습니다. 큰 버튼은 80dp 이상으로 유지하고 작은 화면에서는 세로 배치와 스크롤을 사용합니다.

공조는 OS 하단에서 확인할 수 있는 수치를 반복 나열하지 않습니다. 현재 상태가 저장된 선호와 같은지 비교해 ‘엄마의 선호와 같아요’, ‘직접 조정된 공조예요’, ‘공조 시스템이 꺼져 있어요’ 등으로 구분합니다. 선호 일치는 등록된 온도가 모든 확인 가능한 온도 구역과 같고, 등록 풍량도 일치하며 전원이 꺼져 있지 않아야 성립합니다. 값을 알 수 없는 경우 일치한다고 추정하지 않습니다. 여러 사람의 선호가 같으면 함께 일치하는 사람 수를 표시합니다.

**다른 취향으로 바꾸기**에서 프로필을 선택하고, 적용 범위를 확인합니다. 온도는 확인 가능한 운전석/조수석 지원 구역에 함께 적용하고 등록 풍량을 공유 구역에 반영합니다. 비워 둔 선호는 현재 값을 유지합니다. 저장된 프로필이 없어도 **공조 직접 조절**로 온도/풍량과 전원을 조절할 수 있습니다.

미디어도 같은 방식으로 프로필의 장르 또는 라디오 채널을 선택합니다. 현재 선호 선택만 반영하며 추천 음원 재생, 외부 음악 앱 조회, 실제 라디오 수신은 연결 전임을 표시합니다.

## 게스트와 저장된 프로필

앱을 처음 실행하면 저장 프로필과 좌석 연결을 분리합니다. 탑승 신호가 있어도 자동으로 사람을 식별하지 않으며 ‘게스트’로 표시합니다. 비어 있는 좌석은 ‘빈자리’로 표시합니다. 모든 좌석에 **탑승자 변경**을 제공해 기존 프로필, 새 프로필, 게스트를 선택할 수 있습니다.

- **게스트로 이용**: 프로필 연결만 해제하고 현재 차량 설정 유지
- **기존 프로필 선택**: 적용할 좌석 설정을 확인한 뒤 불러오기. 공조와 음악은 유지
- **새 프로필 생성**: 현재 좌석 값을 가져와 이름과 필요한 선호를 등록. 관계는 선택사항
- **프로필로 저장**: 게스트의 현재 좌석 설정을 새 프로필에 저장하거나 기존 프로필에 덮어쓰기
- **지금 상태 저장**: 연결된 프로필의 좌석 설정을 확인 후 덮어쓰기. 다른 공통 선호는 유지
- **저장 설정 복원**: 저장된 자세/열선/통풍을 현재 좌석에 다시 적용. 현재 수동 조정값이 교체됨을 사전에 안내

프로필 저장은 차량 조절과 별개의 동작입니다. 저장 과정에서 값을 수정했다면 ‘저장 설정 복원’으로 차량에 적용할 수 있습니다. 확인 불가/미지원 값은 신규 저장 시 비워두고, 기존 프로필을 현재 상태로 갱신할 때는 기존 값을 유지합니다.

## 프로필 관리와 선택

상단의 **프로필 관리**에서 관리창을 엽니다. 관리와 탑승자/덮어쓰기/공조/미디어 선택은 같은 목록 컴포넌트를 사용합니다. 실제 탑승 신호가 있고 좌석에 연결된 프로필이 목록 위쪽에 표시됩니다. 가족, 친구, 동료, 기타, 미지정 관계를 필터링할 수 있습니다. 관계는 직접 입력하는 분류이며 취향을 추정하는 근거로 사용하지 않습니다. 기존 프로필의 관계 값은 미지정으로 이어받습니다.

## 기본 프로필과 실제 차량 상태

앱은 실제 차량 상태 화면 하나만 제공합니다. 모드 전환 버튼, 예시 배너와 가상 차량 상태는 제거했습니다. 우측 상단에는 차량 테스트와 프로필 관리 버튼만 둡니다.

기존 예시의 아빠, 엄마, 서연, 할머니, 민지, 지훈 프로필과 저장 선호를 일반 프로필로 한 번 이전합니다. 기존 기기 프로필은 보존하며 같은 ID의 프로필을 덮어쓰지 않습니다. 이전 완료 여부를 저장하므로 재실행 때 중복 생성하지 않고, 사용자가 수정하거나 삭제한 내용도 그대로 유지합니다.

프로필 이전으로 좌석 이름, 탑승 신호, 공조/좌석 설정을 자동 지정하지 않습니다. 인식된 동승자는 프로필 선택 전까지 게스트이며 저장된 선호는 사용자가 불러올 때 차량에 적용합니다. 실제 차량 연결이 없으면 가상 상태로 대체하지 않습니다.

## 자체 UX 검토와 대응

1. 저장과 적용을 혼동하지 않도록 버튼/확인 문구에서 변경 대상을 명시합니다. 게스트 전환과 프로필 삭제도 차량 설정을 초기화하지 않습니다.
2. 같은 사람을 여러 좌석에 배정하지 않습니다. 다른 좌석에서 이동할 경우 연결을 옮긴다는 내용을 확인합니다.
3. 확실한 ‘탑승 → 빈자리’ 신호에서 해당 좌석의 이름을 해제해 다음 사람이 이전 이름을 물려받지 않도록 합니다. 일시적인 확인 불가 신호에는 연결을 지우지 않습니다.
4. 기존 프로필 덮어쓰기와 저장 설정 복원은 내용을 확인한 뒤 진행합니다. 수정 중 창을 닫으면 작성 취소를 확인하며 취소 후 내용이 유지됩니다.
5. 빈 프로필 목록과 필터 결과 없음 상태에 안내와 전체 목록 복귀 경로를 제공합니다. 공조는 프로필 없이 직접 조절할 수도 있습니다.
6. 적용 중에는 중복 요청을 제한하고 진행 표시를 제공합니다. 실제 값 재조회로 반영 여부를 확인하며 일부 실패를 모두 성공으로 표시하지 않습니다.
7. 같은 문구가 반복되는 버튼에는 사람/좌석 정보를 접근성 설명으로 함께 제공합니다.
8. 큰 버튼을 유지하며 좌석 정보의 중복을 줄입니다. 작은 앱 영역에서는 기능을 숨기거나 축소하는 대신 스크롤로 접근합니다.

프로필은 기기 내부에 저장합니다. 실제 차량용 기능 권한, 주행 제한과 실제 오디오 정책은 후속 검증 대상이며 현재 제어는 개발용 Pleos 에뮬레이터 기준입니다.
