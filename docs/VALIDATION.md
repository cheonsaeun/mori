# 환경과 디자인 검증

검증일: 2026-11-11. Apple Silicon Mac, Pleos Connect 2.1.0 / Android API 34 기준입니다.

## 로컬 검증

- Java 17 / Gradle 8.10.2로 assembleDebug와 lintDebug 통과, Lint 오류 0건
- 앱 설치와 최종 대시보드 실행
- 실제 좌석 점유, 등받이 위치, 열선, 앞좌석 통풍, 공유 풍량, 공조 전원 조회 성공
- 현재 이미지에서 뒷좌석 통풍은 미지원으로 표시
- 온도 capability의 구역은 조회되지만 현재 온도 값은 확인 불가로 반환되어 화면에서도 확인 불가로 표시
- 실제 데이터와 디자인 미리보기 전환
- 조수석 선택 시 하단 자세 정보가 해당 예시 위치값 34로 변경
- 음악/라디오 예시 탭 전환
- 스타일 가이드 진입과 복귀, 2560x1440 차량 화면에서 배치 확인

현재 폴링은 화면 활성 상태에서 조회 완료 후 약 2초 간격으로 수행합니다. 실제 차량 제어와 음원 재생은 포함하지 않습니다. 로고는 제공된 이미지 초안을 개발용 벡터로 재구성한 버전입니다.
